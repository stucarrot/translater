⚙️ 고급 실험 옵션 (선택)
아래 값으로 자막/문서 기본 프로파일을 덮어쓰기
🆕 문서(.txt/.epub/.fb2)는 이제 캘리버 번역 플러그인 기본값과 동일하게 문단 하나씩 개별 번역합니다(마커/문맥윈도우 없음) — 그래서 위 6개 항목 중 "동시 처리 개수"만 문서에 적용되고, 나머지(청크 목표/최대 블록 수, 청크 글자수 상한, 문맥 윈도우 앞/뒤)는 자막(.srt/.vtt)에만 적용됩니다. 비활성 상태면 입력값은 무시되고 자동 프로파일을 씁니다. 동시 처리 개수를 너무 높이면 구글이 일시 차단(429/403)할 수 있어요.
🆕 문서: '합니다체' → '하다체' 변환 시도 (실험적)
구글 번역이 소설도 대부분 정중체(합니다체)로 번역하는 경향이 있어, 과거형 어미(~았/었습니다→~았/었다)와 계사(입니다→이다) 위주로 서술체에 가깝게 후처리합니다. 현재형 동사(예: 갑니다→간다)는 한국어 활용이 복잡해 다루지 못해 그대로 남을 수 있습니다 — 완벽하지 않은 부분 변환입니다. 문서(.txt/.epub/.fb2)에만 적용되며 자막에는 적용되지 않습니다.
🆕 번역 캐시 사용 (브라우저에 저장, 재작업 시 같은 문장 재요청 안 함)
언어쌍+용어고정 조합별로 캐시가 저장됩니다. 같은 파일을 다시 돌리거나 중간에 실패해도, 이미 번역된 문장은 구글에 다시 묻지 않고 캐시에서 바로 채웁니다.
🆕 Google 새 엔드포인트 우선 시도 (캘리버 기본 추천값)
캘리버 번역 플러그인이 "casual user에게 추천"으로 명시한 translate-pa.googleapis.com 엔드포인트를 먼저 써봅니다. 번역 시작 시 1회 접속 테스트 후, 되면 계속 이걸 쓰고 브라우저 CORS 등으로 막히면 자동으로 기존 방식(translate_a/single)으로 전환됩니다 — 상태는 여기 표시됩니다.
🆕 Google AI Studio(Gemini) API로 번역 (내 API 키 사용)
프롬프트 안의 {{SRC}}·{{TGT}}는 각각 출발/도착 언어명, {{TEXT}}는 실제 원문으로 자동 치환됩니다. {{TEXT}}를 지워도 번역이 깨지지 않게 뒤에 원문을 안전하게 덧붙이지만, 위치를 제어하려면 남겨두는 걸 권장합니다. 마커 보존 규칙 줄은 되도록 남겨두세요 — 지우면 자막 타이밍/문단 매칭이 깨질 수 있습니다. 수정 즉시 저장되며, 다음 번역부터 바로 적용됩니다.
켜면 모든 번역 요청이 무료 구글 엔드포인트 대신 입력한 API 키로 Gemini(Google AI Studio)에 직접 전송됩니다(우선순위 최상단 — 위의 "새 엔드포인트" 옵션보다 먼저 시도됨). 키를 여러 줄로 여러 개 등록하면 요청마다 돌아가며 사용하고, 한 키가 쿼터 초과(429) 등으로 실패하면 같은 요청 안에서 자동으로 다음 키를 시도합니다. 등록된 모든 키가 실패해야 그 호출만 기존 구글 번역으로 폴백합니다. 키는 localStorage에만 저장되며 이 코드 자체에는 들어가지 않습니다. 자막과 문서는 서로 다른 프롬프트(아래)를 쓰며, 러시아어 원문에 대한 말투·생략 주어·인명 표기 지침이 기본으로 들어가 있습니다 — 다른 언어쌍에도 그대로 써도 무방합니다.
